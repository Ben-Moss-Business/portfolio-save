# Ben Moss | Portfolio 

Welcome to my portfolio! This project is a digital showcase of my work as a **Web Developer**. It features a high-performance 3D environment and a "Bento-style" grid layout to document both software applications and mechanical rebuilds.

**Live Demo:** [https://ben-moss-business.github.io/portfolio-save/](https://ben-moss-business.github.io/portfolio-save/)

---

## The Tech Stack

### Frontend & Graphics
* **React.js** - Component-based UI architecture.
* **Three.js** - Interactive 3D low-poly environment and kinematics.
* **Node.js** - Lightning-fast build tool and development server.

---

## Key Features

### 1. The 3D Hero
An immersive landing page using **Three.js** to render a dynamic landscape that responds to user interaction.

### 2. Project Bento Grid
A curated selection of full-stack projects, including:
* **Low Waste Looper:** A sustainability platform built for the BPC Hackathon 2025.
* **Online Restaurant:** A MERN-stack ordering system with an admin dashboard.
* **2D Physics Engine:** A custom-built kinematics simulator.

### 3. The Garage
A unique section dedicated to mechanical engineering, featuring a progress tracker for my **Honda CBF rebuild** and a "Now Playing" music widget.
